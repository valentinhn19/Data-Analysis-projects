01

Mean

Descriptive

The mean (arithmetic average) sums all values and divides by how many there are. It's the balancing point of a distribution — the value where the data would perfectly balance if placed on a scale.

FORMULA x̄ = (Σxᵢ) / n  =  (x₁ + x₂ + ... + xₙ) / n

02

Median

Descriptive

The median is the middle value when data is sorted. It's robust to outliers — extreme values don't distort it. For an even number of values, take the average of the two middle ones.

FORMULA Median = value at position (n+1)/2 when sorted  |  If n is even: avg of n/2 and n/2+1

03

Mode

Descriptive

The mode is the value that appears most frequently. It's the only measure of central tendency that applies to categorical data (like positions). Continuous data like WAR rarely has a meaningful mode — binned data does.

Standard Deviation

Descriptive + Foundation for Inference

Standard deviation (σ or s) measures how spread out values are around the mean. A low SD means players are similar; a high SD means there's huge variation — a few legends and many average players.

SAMPLE SD s = √[ Σ(xᵢ − x̄)² / (n−1) ]
1Find the mean (x̄)
2Subtract mean from each value: (xᵢ − x̄)
3Square each difference: (xᵢ − x̄)²
4Sum them all up: Σ(xᵢ − x̄)²
5Divide by (n−1) and take the square root

Normal Distribution

Inference Foundation

The bell curve describes how naturally occurring measurements cluster around the mean. It's symmetric: 68% of data falls within ±1σ, 95% within ±2σ, and 99.7% within ±3σ. This is called the empirical rule.

PDF f(x) = (1 / σ√2π) · e^(−½((x−μ)/σ)²)

Hypothesis Testing

Inferential

Hypothesis testing answers: "Is the difference I observe real, or just random chance?" We set up two competing claims and let the data decide — using probability as the judge.

H₀ — NULL HYPOTHESIS
There is no difference between DR and PR players.
μ_DR = μ_PR
H₁ — ALTERNATIVE HYPOTHESIS
There is a difference between DR and PR players.
μ_DR ≠ μ_PR

Confidence Intervals

Inferential

A confidence interval (CI) gives a range of plausible values for a population parameter. A 95% CI means: if you repeated this study 100 times, 95 of the resulting intervals would contain the true mean.

95% CI FOR MEAN CI = x̄ ± t*(s / √n)  =  x̄ ± Margin of Error

Regression Analysis

Inferential

Linear regression models the relationship between variables with a straight line. It answers: "Given a player's home runs, what WAR do we expect?" The line minimizes squared distances from points to the line (ordinary least squares).

LINEAR MODEL ŷ = β₀ + β₁x  +  ε  →  WAR = intercept + (slope × HR) + error

ANOVA

Inferential

Analysis of Variance (ANOVA) tests whether the means of three or more groups differ significantly. It compares the variance between groups to the variance within groups using an F-statistic.

F-STATISTIC F = (Between-group variance) / (Within-group variance)  =  MS_between / MS_within

Correlation Analysis

Pearson · Spearman

Pearson correlation (r) measures linear relationships between two continuous variables. Spearman correlation (ρ) measures monotonic relationships using ranks — more robust to outliers and non-normal data.

PEARSON r r = Σ[(xᵢ−x̄)(yᵢ−ȳ)] / √[Σ(xᵢ−x̄)² · Σ(yᵢ−ȳ)²]    range: −1 to +1
